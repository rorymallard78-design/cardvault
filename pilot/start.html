Welcome to CardVault

Organize your sports cards, track purchases and sales, and try AI-assisted photo identification. Your invitation includes up to 50 free AI card scans.

Open CardVault PilotRead the full user guide
About 2–3 minutes

Activate your invitation

  1. Open CardVault Pilot using rorymallard78-design.github.io/cardvault/pilot/ in Chrome (Android) or Safari (iPhone).
  2. Open Settings using the gear icon near the top of the app.
  3. Find “Beta AI Scanning — 50 Free Scans.” Paste the private invitation code sent to you. It starts with CV-.
  4. Tap “Activate 50 Free Scans.” You should see “Invitation accepted” and your remaining scan allowance. No API key or Cloudflare setup is needed.
  5. Add your first card. Tap +, select Add One Card, then Take a Photo or upload an image. Check the AI results and enter your purchase cost before saving.
Good to know: You don't need to install the app to use it. AI scans use your invitation allowance; manual card entry remains available when those scans are gone.

Install on Android

  1. Open the Pilot link in Chrome.
  2. Tap Chrome's ⋮ menu.
  3. Choose Install app or Add to Home screen, if available.
  4. Open CardVault using that shortcut.

Browser wording varies by phone and version.

Install on iPhone

  1. Open the Pilot link in Safari.
  2. Tap the Share icon.
  3. Choose Add to Home Screen.
  4. Tap Add and launch CardVault.

If the link opened inside a messaging app, first choose “Open in Safari.”

Before adding lots of cards

  • Back up your collection. Settings → Data → Export Complete Backup (Including Photos). Save the JSON file outside your browser, ideally in a cloud drive.
  • Your data is stored on this device. There is no automatic cloud sync or user account in this beta. Using another phone, browser, or browser profile may show an empty collection.
  • Double-check scans. AI can misidentify card years, sets, parallels, serial numbering, and grades. Correct errors before saving.
  • Keep your invitation private. Do not send passwords or API keys. Each tester should have their own code.

What should I test?

Try adding a photo-scanned card and a manually entered card, editing a card, recording a sale, exploring Dashboard/Insights, and exporting a complete backup. If something fails, report what you tapped, what happened, and (when safe) a screenshot to the person who invited you.
